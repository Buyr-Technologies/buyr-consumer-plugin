# Buyr

Set your price on the world's best brands. Unlock deals automatically with AI-powered matching.

The World's Best Brands at the Prices You Set.

This is the Buyr shopper Agent Plugin. It talks to `https://shopapp.buyr.com/mcp/consumer` and shops [https://www.buyr.com](https://www.buyr.com).

## What a shopper can do

1. Search negotiable products on the Buyr store.
2. Name a price and preview the quote.
3. Submit the offer after linking a Buyr account.
4. Check the offer, then check out on the Buyr store when it is accepted.
