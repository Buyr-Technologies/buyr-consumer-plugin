# Buyr consumer plugin

One Agent Plugin for ChatGPT and Grok Bot. The MCP URL is `https://shopapp.buyr.com/mcp/consumer`.

A shop appears in search only when `consumer_agent_plugin` is enabled for that shop. Product links use the shop hostname stored on the shop row.

ChatGPT: zip this directory and upload it in the OpenAI plugin draft.
Grok Bot: publish this directory from a public repo and submit that repo at https://cursor.com/marketplace/publish.
