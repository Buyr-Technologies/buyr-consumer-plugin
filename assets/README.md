## Walkthrough video script (placeholder)

1. User asks ChatGPT to find a negotiable product.
2. Buyr returns an eligible product card with a price range hint.
3. User names a price and confirms the offer.
4. Merchant accepts; user taps **Open checkout** and lands on the merchant store.

## Naming

Use `buyr-chatgpt-<asset>-<variant>.<ext>` (e.g. `buyr-chatgpt-icon-512.png`).
